# Archived pages

Pages removed from the live site but kept for reuse. To restore one, move it back into `pages/` (e.g. `git mv archive/pages/services.js pages/services.js`), re-add its nav/footer link, and remove the matching redirect in `next.config.js`.

- `services.js` — the all-services overview (accordion of every category). Removed Sep 2026; the homepage medallions and /services/<slug> pages cover it.
